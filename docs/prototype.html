应用与账户的关系

  • 一个应用：对应商业开放平台的一组 App ID / Secret，可授权多个广告账户与主体。
  • 多个应用：不同主体或代理商各自建应用，凭证、授权范围与有效期互不影响；任一应用失效只影响它名下的账户。
  • 账户映射：已授权账户再与门店做多对多绑定，决定广告消耗如何归因；移除应用会同时解除其账户映射。
