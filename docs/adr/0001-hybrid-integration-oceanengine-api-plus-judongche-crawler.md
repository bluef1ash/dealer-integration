# 混合集成策略：巨量引擎走官方 Marketing API，巨懂车走网页会话爬取

前期调研认为两边都只能爬虫。实际核实：巨量引擎商业开放平台（open.oceanengine.com）对企业主体开放 Marketing API，报表（账户/广告组/自定义报表、线索归因）接口齐全；巨懂车没有任何公开的线索 API（懂车帝开放平台只有车型库等内容接口）。决定：巨量引擎侧用公司主体申请代理商型开发者，各广告主 OAuth 授权后走官方 API 取数；巨懂车侧维持爬虫方案。爬虫风险面因此收窄到只剩巨懂车。

代价：开发者申请以周计，需在开发前启动；若申请被拒，回退方案是巨量广告后台也走爬取（风险与工作量显著上升，届时需重新评估）。
